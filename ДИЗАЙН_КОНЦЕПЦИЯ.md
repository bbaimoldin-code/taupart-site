# Дизайн-концепция — сайт Tauman Partners (Premium Corporate)

Последнее обновление: 2026-09-14. Формат: текстовая дизайн-концепция + визуальный макет (canvas-артефакт, ссылка у владельца).

## 0. Статус решений (актуально на 2026-09-14)

- **Направление**: изначально рассматривалось два варианта — реалистичный одностраничник (B) и амбициозный многостраничник в духе Big Four (A). **Владелец выбрал Вариант A** — в работу идёт он.
- **Юридическая терминология выверена** по Закону РК «Об оценочной деятельности в Республике Казахстан» № 133-VI: компания занимается **оценкой** (результат — отчёт об оценке), а не «экспертизой» в широком смысле — «экспертиза отчёта об оценке» отдельная процедура **Палаты оценщиков**, не услуга компании. Раздел «Экспертиза» переименован в **«Объекты оценки»** / **«Когда нужна оценка»**; «СРО» заменено на **«Палата оценщиков»**.
- **Реальный контент получен** из корпоративной презентации компании (файл «Текст презентации.docx») и от владельца напрямую — контакты, услуги, референс-проекты, актуальные показатели. Заменил все плейсхолдеры/выдумки, где это было возможно (см. раздел 5).
- Макет опубликован как canvas-артефакт (3 артборда: сравнение B/A, страница «Партнёрам»), обновляется по ходу правок.
- **Сайт будет трёхъязычным** (решено владельцем 2026-09-14): казахский / русский / английский, с профессиональным переводом (не машинным). Это архитектурное решение — нужен переключатель языка в хедере и структура контента, готовая под три версии текста. Пока весь контент в макете и в этом документе — на русском (рабочий/исходный язык для перевода); казахский и английский тексты не переводятся автоматически без запроса — см. открытые вопросы.

## 1. Позиционирование

Первое впечатление, которое обязан давать сайт: *«Это серьёзная профессиональная оценочная компания, работающая по признанным стандартам»*.

Реальная формулировка компании (из презентации, используем как есть — она уже хороша и не банальна):

> **Eyebrow:** Эксперты по оценке имущества и интеллектуальной собственности
> **Headline:** Оценка, которой доверяют банки, суды и собственники.
> **Value proposition / таглайн компании:** «С нами надёжно!» — отчёты, подготовленные нашими специалистами, полностью соответствуют требованиям законодательства и стандартов Республики Казахстан, международных норм МСФО (IAS, IFRS).

## 2. Принципы из референсов (без копирования)

Общее у Big Four / банков / топ-консалтинга — не декор, а дисциплина:

- Доверие создаётся **специфичностью** (номер квалификационного свидетельства оценщика, членство в Палате оценщиков, конкретные цифры, названные проекты), а не декоративными элементами.
- Много воздуха (whitespace) вместо плотной вёрстки.
- Один акцентный цвет, используемый скупо; фон — почти всегда белый/нейтральный.
- Крупная, уверенная типографика с чёткой иерархией.
- Motion — незаметный: лёгкое проявление при скролле, плавный hover.
- Навигация — mega-menu оправдан только там, где реально много вложенных разделов.

## 3. Дизайн-система

### 3.1 Типографика

Основной шрифт (заголовки): **Manrope**, 700/800 — современный geometric grotesk, хорошо читается крупным кеглем, бесплатный (Google Fonts), не датируется.

Вторичный шрифт (текст): **Source Sans 3**, 400/600 — нейтральный, высокая читаемость мелким кеглем, достаточно отличается от Manrope, чтобы пара читалась как осознанная иерархия.

Шкала (значения — desktop 1440 / mobile 390, line-height множитель):

| Уровень | Desktop | Mobile | Line-height | Weight |
|---|---|---|---|---|
| Display (hero H1) | 64px | 36px | 1.1 | Manrope 800 |
| H1 | 48px | 32px | 1.15 | Manrope 800 |
| H2 | 36px | 26px | 1.2 | Manrope 700 |
| H3 | 28px | 22px | 1.25 | Manrope 700 |
| H4 | 20px | 18px | 1.3 | Manrope 700 |
| Body Large | 20px | 18px | 1.5 | Source Sans 400 |

### 3.2 Сетка и масштаб

- Desktop max-width контейнера: 1440px, содержимое — 1200px внутри с боковыми полями по 120px (на 1280px — поля 80px).
- 12-колоночная сетка, gutter 24px.
- Breakpoints: Desktop 1440 / Laptop 1280 / Tablet 768 / Mobile 390.
- Базовая единица отступов — 8px (шаг 8/16/24/32/48/64/96/128).

### 3.3 Цвет

- Фон: `#ffffff` (основной), `#f4f6f8` (секции-паузы)
- Акцент: `#17457a` (тёмно-синий) — CTA, ссылки-акценты, тёмный блок "О компании"
- Текст: `#1a1d23` (основной), `#5c616a` (вторичный), `#8a8f97` (третичный/подписи)
- Линии: `#e4e6ea`
- Без градиентов, без вторых акцентных цветов

### 3.4 Абстрактная графика (hero)

Изначально в макете стояла условная столбчатая диаграмма. Владелец прислал референс-изображение (стоковый превью-лист «Creative Poster Design», 8505.jpg/eps) с идеей сетки из тонких линий и узлов — но сам файл сток-превью с радужными градиентами и текстом Lorem Ipsum, не годится напрямую (противоречит брифу: без градиентов, без стока). **Взята только композиционная идея**: перерисована как собственная abstract-графика — тонкая навy-сетка из точек и линий (network/analytics motif), без градиентов, без текста, в палитре проекта. Используется в hero обоих вариантов макета.

### 3.5 Motion

- Hover на ссылках/строках услуг: подчёркивание или сдвиг стрелки `→`, 150–200ms ease-out
- Scroll-reveal: fade + сдвиг на 12px, 400ms, срабатывает один раз, без параллакса
- Переход мега-меню: 200ms, без bounce/spring-эффектов
- Никаких лоадеров, 3D, скролл-джекинга

## 6. Страница «Партнёрам»

Отдельная страница для B2B-партнёров (банки, риелторские агентства, частные брокеры). Референс структуры дал владелец (сайт конкурента), визуально пересобрано в фирменной системе (navy вместо оранжевого конкурента, тонкие обводки вместо заливных иконок — брендинг конкурента не копируем, только структуру).

Состав:
1. Заголовок «Партнёрская программа» + вступление
2. Сетка из 6 преимуществ: спецусловия по стоимости, комиссия за клиента, бесплатный предварительный расчёт, выезд в нерабочее время, приоритетные сроки, отслеживание заявок по трек-коду
3. Форма «Стать партнёром»: имя, организация, телефон, email, комментарий

Конкретные условия (размер комиссии и т.п.) — не определены, см. открытые вопросы.

## 8. Responsive и доступность

- Мобильная версия — не сжатый desktop: навигация сворачивается в полноэкранное меню, отступы секций сокращаются вдвое, сохраняя кратность 8px.
- Контраст текста/фона — минимум AA.
- Все интерактивные элементы — видимый focus-state, понятные CTA.

## 9. Что исключаем
