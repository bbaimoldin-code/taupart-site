Публичный сайт компании ТОО "Tauman Partners" (оценочная компания,
Казахстан). Директор-оценщик — Баймолдин Бакытжан Нуржанулы. Домен уже

Это отдельный проект от C:\ReportExport (выгрузка истории отчётов сайта

## Как появился этот проект

Идея и черновой выбор дизайна обсуждались в чате ReportExport (там же,
где ведётся выгрузка отчётов) — по накопленной практике компании: сначала
прикинуть на канвасе несколько стилевых направлений, определиться, и
только потом заводить сайт отдельным проектом. Сам сайт с этого момента
разрабатывается здесь, в отдельном чате/папке.

## Выбранное стилевое направление — "Colliers-style"

Владелец попросил ориентироваться на стилистику трёх сайтов: apple.com,
deloitte.com, colliers.kz. Было сделано три варианта в духе каждого, и
выбран вариант в стиле **colliers.kz** (профессиональный консалтинг по
недвижимости — ближайший по духу к оценочному бизнесу): чистый белый фон,
тёмно-синий акцент, услуги списком со стрелками, блок статистики
(годы опыта / кол-во отчётов), ряд логотипов партнёров/банков для доверия.

**Почему именно этот вариант, а не Apple-style или Deloitte-style:**
Apple-style (предельный минимализм, огромные заголовки, "продуктовые"
секции) и Deloitte-style (плотная корпоративная вёрстка с языковой
полосой, пилларной навигацией, блоком публикаций) были показаны как
альтернативы на том же канвасе — при желании к ним можно вернуться, но
выбор пал на Colliers-style как наиболее близкий по духу к нише
(оценка/консалтинг по активам).

### Ключевые визуальные параметры (снять с макета при вёрстке)

- Шрифты: заголовки — **Manrope** (700/800), текст — **Source Sans 3**
  (400/600). Оба через Google Fonts.
- Палитра: белый фон `#ffffff`, тёмно-синий акцент `#17457a`, светло-серый
  фон секций `#f4f6f8`, текст `#1a1d23`, второстепенный текст `#5c616a`/
  `#8a8f97`, линии-разделители `#e4e6ea`.
- Композиция главной страницы (сверху вниз):
  1. Хедер: логотип слева, навигация (Услуги / О компании / Публикации /
     Контакты) + кнопка-акцент "Статус заказа" справа.
  2. Хиро: эйбрkoу-лейбл, крупный заголовок (H1), короткий подзаголовок,
     две кнопки (основная — "Оставить заявку", вторичная — "Узнать статус
     заказа").
  3. Полоса статистики на 3 колонки (серый фон): годы опыта / кол-во
     отчётов / география работы.
  4. Услуги — не карточками, а списком строк с стрелкой `→` справа,
     разделены тонкой линией (приём Colliers).
  5. Блок "О компании" на тёмно-синем фоне: текст про директора-оценщика
     + список доверия (аттестация, СРО, статус заказа онлайн).
  6. Ряд логотипов партнёров/банков (плейсхолдеры).
  7. Контакты (текст) + плейсхолдер карты.
  8. Футер: копирайт + ссылка "Вход для сотрудников" (без выделения,
     мелким текстом).

копировать формат канваса.

## Решено ранее (при планировании, до выбора дизайна)

- **Вход для сотрудников** — не отдельная система логина, а
  точка входа (ссылка/кнопка), ведущая в Telegram Mini App или на
  HTTPS-адрес ReportExport с проверкой роли сотрудника. Логику
  ReportExport сюда не копировать.
- **Статус заказа для клиента** — без логина/пароля. Клиенту даётся
  трек-ссылка/трек-код вида `сайт.kz/status/<код>` (по аналогии с
  курьерскими службами), по которой виден статус без пароля. Причина:
  явный отказ владельца от логина/пароля клиентам — меньше
  ответственности за хранение персональных данных, не будет проблемы
  "клиент забыл пароль". Статус заказа — отдельная сущность (не часть
  архива ReportExport), меняется вручную оценщиком или автоматически при
  появлении отчёта в реестре ReportExport.
