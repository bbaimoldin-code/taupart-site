# Контекст проекта

Перед началом работы обязательно прочитай **ИСТОРИЯ_ПРОЕКТА.md** в этой же
папке — там полный контекст: что это за сайт, почему выбрано именно это
стилевое направление, и что уже решено по структуре/функционалу.

Краткая суть: сайт компании ТОО "Tauman Partners" (оценочная компания,
директор-оценщик Баймолдин Бакытжан Нуржанулы) — публичная часть для
клиентов (услуги, о компании, контакты, отслеживание статуса заказа по
трек-коду без логина/пароля) + отдельный вход для сотрудников (ссылка,
ведущая в ReportExport/Telegram Mini App — логика туда не дублируется).

Два других, независимых проекта той же компании — в соседних папках
C:\ReportExport, C:\ReportMonitor и C:\ReportAutofill — у них свои
CLAUDE.md/ИСТОРИЯ_ПРОЕКТА.md, сюда их контекст подтягивать не нужно.
Наоборот, детали дизайн-макетов и это решение изначально обсуждались в
чате ReportExport — там, если нужно, можно найти историю выбора
стилистики, но дальнейшая работа над сайтом ведётся здесь, отдельно.
